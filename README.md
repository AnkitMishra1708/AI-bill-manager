# Ai Bill Manager

This is Ai Bill Manager which is a full-stack AI-powered bill management application that allows users to upload bills, extract invoice information using AI, and manage their invoices in one place.

## Flow

```text
Frontend
   ↓
Upload Bill
   ↓
Backend
   ↓
Cloudinary
   ↓
AI Invoice Extraction
   ↓
Extracted Data
   ↓
Database
```
